# LINE Learning LIFF

หน้า `/login` ยืนยัน LINE ID token กับ backend; หน้า `/` แสดงหน้าแรก หมวดการเรียน (ฝึกทำโจทย์ ผลเรียน เอกสาร) หมวดงานและแผน (งานที่ต้องทำ แผนอ่านสอบ) และตั้งค่าการแจ้งเตือน **การถามบทเรียนด้วย AI ทำได้ผ่านแชต LINE เท่านั้น ไม่ส่งคำถามจาก LIFF** ครูจะเห็นหมวดสำหรับครูพร้อมเมนูย่อยแยกการอัปโหลด/ตรวจไฟล์/สร้างโจทย์ และตรวจคำตอบ/จัดหัวข้อ/ตั้งค่าวิชา และตรวจรับระบบ

ตั้ง `NEXT_PUBLIC_LIFF_ID` กับ `NEXT_PUBLIC_API_URL` ตาม `.env.example` และเปิด scope `openid` ใน LIFF ตั้ง backend CORS ให้ตรง origin ของเว็บ

```bash
npm ci
npm run dev
npm run lint
npm run build -- --webpack
npm start
```

การเข้าสู่ระบบต้องใช้ LINE จริง ไม่มีโหมดปลอมตัวเป็นครูใน browser Token อยู่ในหน่วยความจำและยืนยันใหม่หลัง reload หน้า settings แสดง UUID สำหรับให้ผู้ดูแลเพิ่มรายวิชา รายละเอียด provisioning, Railway Bucket และ worker อยู่ใน README ที่ root

Railway ใช้ Root Directory `liff` กับ Dockerfile นี้ กำหนด public variables ก่อน build และใช้ PORT ที่ Railway จัดให้ Next standalone server อ่าน PORT ได้อัตโนมัติ

เลือกรายวิชาในหน้าแรกเพื่อฝึกและดูเอกสาร แล้วกด “ใช้วิชานี้ในแชต LINE” เพื่อกำหนดวิชาสำหรับข้อความถาม AI ถัดไป แบบฝึกมีปรนัย จริง/เท็จ ตัวเลข คำตอบสั้น เซตจำนวนเต็ม และคำตอบอธิบายที่รอครูตรวจ ผลตรวจแสดงในหน้าความก้าวหน้า

หน้าหลักฐานตรวจรับมีแบบฟอร์มกำหนดกรณีทดสอบประจำวิชา 80 กรณี ต้องจัดชุดให้ครบก่อนเริ่มให้คะแนน การแก้ขอบเขตหรือชุดทดสอบทำให้ต้องประเมินรอบใหม่

เมนู Rich Menu เก่าที่เปิด `?view=ask` จะถูกนำมาหน้าแรก (`?view=home`) แทน ไม่เปิดฟอร์มแชต AI บนเว็บ และ `POST /chat` สำหรับหน้าเว็บถูกปิด ฝั่ง LINE Webhook/Worker ยังเป็นช่องทางถาม AI ตามเดิม
