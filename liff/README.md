# LINE Learning LIFF

หน้า `/login` ยืนยัน LINE ID token กับ backend; `/` แสดงงาน แบบฝึก แผน ความก้าวหน้า เอกสาร และตั้งค่า (ถาม AI ในแชต LINE OA เท่านั้น ไม่ใช่บนเว็บ) ครูที่มีสมาชิกวิชาตามสิทธิ์จะเห็นการตั้งวิชา/หัวข้อ สร้างวิชาในโรงเรียนเดิม ตรวจคำตอบอธิบาย จัดเอกสารและหลักฐานตรวจรับ

ตั้ง `NEXT_PUBLIC_LIFF_ID` กับ `NEXT_PUBLIC_API_URL` ตาม `.env.example` และเปิด scope `openid` ใน LIFF ตั้ง backend CORS ให้ตรง origin ของเว็บ

```bash
npm ci
npm run dev
npm run lint
npm run build -- --webpack
npm start
```

การเข้าสู่ระบบต้องใช้ LINE จริง ไม่มีโหมดปลอมตัวเป็นครูใน browser Token อยู่ในหน่วยความจำและยืนยันใหม่หลัง reload หน้า settings แสดง UUID สำหรับให้ผู้ดูแลเพิ่มรายวิชา รายละเอียด provisioning, Railway Bucket และ worker อยู่ใน README ที่ root

Railway ใช้ Root Directory `liff` กับ Dockerfile นี้ กำหนด public variables ก่อน build และใช้ PORT ที่ Railway จัดให้ Next standalone server อ่าน PORT ได้อัตโนมัติ

เลือกรายวิชาในหน้าแรกเพื่อฝึกและดูเอกสาร หากต้องการถามบทเรียนด้วย AI ให้กด “ใช้วิชานี้ในแชต LINE” แล้วส่งคำถามในห้องแชต LINE OA โดยตรง เว็บไซต์ไม่มีฟอร์มส่งคำถาม AI แบบฝึกมีปรนัย จริง/เท็จ ตัวเลข คำตอบสั้น เซตจำนวนเต็ม และคำตอบอธิบายที่รอครูตรวจ ผลตรวจแสดงในหน้าความก้าวหน้า

หน้าหลักฐานตรวจรับมีแบบฟอร์มกำหนดกรณีทดสอบประจำวิชา 80 กรณี ต้องจัดชุดให้ครบก่อนเริ่มให้คะแนน การแก้ขอบเขตหรือชุดทดสอบทำให้ต้องประเมินรอบใหม่
