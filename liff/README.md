# LINE Learning LIFF

หน้า `/login` ยืนยัน LINE ID token กับ backend; หน้า `/` ใช้เลือกรายวิชาและพากลับไปเรียนใน LINE เมนูหลักของนักเรียนมี **เรียนผ่าน LINE** และ **ตั้งค่าการใช้งาน** การทำข้อสอบ ส่งคำตอบ ขอคำใบ้ และถามบทเรียนอยู่ในแชต LINE ส่วนการตั้งค่าแจ้งเตือน งาน แผนอ่านสอบ ประวัติผล และเอกสารเป็นเมนูรองในตั้งค่า ครูยังมีเมนูอัปโหลด/อนุมัติ PDF จัดรายวิชาและตรวจคำตอบ


ผู้ดูแลใช้ **ผู้ดูแลระบบ → บัญชีผู้ใช้** ดู/แก้โรงเรียนปัจจุบันและบทบาทครู/นักเรียน พร้อมกรองโรงเรียน/ไม่มีสังกัด/บทบาท ครูที่ยังไม่มีรายวิชาสามารถสร้างวิชาแรกบนหน้าหลักหลังได้รับสังกัดและบทบาทครู รายวิชาที่สร้างเป็นของผู้สร้างอัตโนมัติ หน้ารายวิชาแสดงเจ้าของและเพิ่ม/เอาออกได้เฉพาะนักเรียนในโรงเรียนเดียวกัน บทบาทไม่ถูกแก้จากหน้าสมาชิกรายวิชาแล้ว ต้องใช้ backend ที่รัน migration `20261107_school_roster` และปรับ worker เป็นรุ่นเดียวกัน

ตั้ง `NEXT_PUBLIC_LIFF_ID` กับ `NEXT_PUBLIC_API_URL` ใน `.env.local` หรือ Railway build variables และเปิด scope `openid` ใน LIFF ตั้ง backend CORS ให้ตรง origin ของเว็บ

ตั้ง `NEXT_PUBLIC_LINE_OA_ID` เป็น Basic ID หรือ Premium ID ของบัญชี LINE Learning เช่น `@your-account` ก่อน build เพื่อเปิดปุ่ม **ทำข้อสอบใน LINE** และ **เปิดแชต LINE Learning** ปุ่มแรกเปิดแชตพร้อมข้อความร่าง “ทำข้อสอบ” ผู้เรียนกดส่งเองใน LINE ใช้ [LINE URL scheme](https://developers.line.biz/en/docs/messaging-api/using-line-url-scheme/#opening-a-chat-screen-with-a-line-official-account) โดยไม่ต้องเปิด scope `chat_message.write` หากยังไม่ตั้ง ID ใน LIFF จะแสดงปุ่มกลับไปที่ LINE ส่วน browser ภายนอกแสดงวิธีเปิดแชตด้วยตนเอง ค่า ID นี้เป็นข้อมูลสาธารณะ ไม่ใช่ Channel ID หรือ access token

```bash
npm ci

npm start
```

การเข้าสู่ระบบต้องใช้ LINE จริง ไม่มีโหมดปลอมตัวเป็นครูใน browser Token อยู่ในหน่วยความจำและยืนยันใหม่หลัง reload หน้า settings แสดง UUID สำหรับให้ผู้ดูแลเพิ่มรายวิชา รายละเอียด provisioning, Railway Bucket และ worker อยู่ใน README ที่ root

Railway ใช้ Root Directory `liff` กับ Dockerfile นี้ กำหนด public variables ก่อน build และใช้ PORT ที่ Railway จัดให้ Next standalone server อ่าน PORT ได้อัตโนมัติ

เลือกรายวิชาแล้วกด **ใช้วิชานี้ในแชต LINE** จากนั้นกลับแชตส่วนตัวแล้วพิมพ์ **ทำข้อสอบ** แตะตัวเลือกหรือพิมพ์คำตอบทีละข้อ พิมพ์ **ขอคำใบ้** เพื่อดูคำใบ้พร้อมโจทย์เดิม พิมพ์ **ผลสอบ** เพื่อดูคะแนนและหัวข้อที่ควรทบทวน หรือ **ยกเลิกสอบ** เพื่อกลับไปถามบทเรียน ข้อเขียนที่ครูกำหนดให้ตรวจเองส่งจากแชตได้และรอครูตรวจ โดยยังไม่นับรวมในคะแนนจนกว่าจะตรวจเสร็จ

หน้าหลักฐานตรวจรับมีแบบฟอร์มกำหนดกรณีทดสอบประจำวิชา 80 กรณี ต้องจัดชุดให้ครบก่อนเริ่มให้คะแนน การแก้ขอบเขตหรือชุดทดสอบทำให้ต้องประเมินรอบใหม่

เมนู Rich Menu เก่าที่เปิด `?view=ask` หรือ `?view=practice` จะเปิดหน้าแนะนำการเรียนใน LINE (`?view=home`) และคงปลายทางนี้ผ่านหน้า login ไม่มีฟอร์มรับโจทย์ ส่งคำตอบ หรือขอคำใบ้ใน LIFF สำหรับ Rich Menu ใหม่ใช้ message action ส่งคำว่า **ทำข้อสอบ**, **ขอคำใบ้**, **ผลสอบ** หรือ **ยกเลิกสอบ** ได้โดยตรง ใช้ URI action เปิด LIFF เฉพาะการเข้าสู่ระบบและตั้งค่า ไม่มีการแก้ Rich Menu จริงจากโค้ดชุดนี้


การอัปโหลดไฟล์สอน PDF รุ่นใหม่: OpenAI อ่าน PDF ชุดละ 2 หน้าและบันทึก checkpoint พร้อมคำสำคัญ → ครูเปิดเมนู **สำหรับครู → ไฟล์และแบบฝึก → ดูและแก้ไฟล์** → เทียบข้อความ/สูตร/เลขหน้ากับต้นฉบับ → กรอก Checklist และยืนยันคุณภาพ → กดอนุมัติ. จนกว่าจะอนุมัติ นักเรียนและ AI จะยังไม่เห็นไฟล์นี้. DOCX/TXT ยังคงใช้การสกัดข้อความเดิม ส่วน evidence ไม่ส่งให้ OpenAI.
